# Disclaimer

rea-board gives a best guess, not a promise. A script sorts each issue from its title and its labels, and each pull request from its checks, merge conflicts, draft state and age. It does not read the code or the comments.

## What a card means

- A card can be in the wrong column. A title can mislead, and a label can be missing or wrong.
- An item can be missing from the page. Some groups make no card, as the [README](README.md#the-columns) says.
- The data is as old as the last run of `pull.py`. An item can change on GitHub after that.

Check the item on GitHub before you act on a card.

## At your own risk

You use rea-board at your own risk. Its authors and contributors are not responsible for anything that happens because you acted on a card, or did not.

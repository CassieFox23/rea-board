# Security

## Reporting a problem

Use the private report form: the **Security** tab of this repository, then **Report a vulnerability**. Only the maintainer can read it. Please do not open a public issue for a security problem.

What counts:

- the board writes anything to GitHub: a post, a comment, a label or a close
- a crafted title or label runs script in the page, or breaks out of the escaping
- a file is written outside the data folder

An item sorted into the wrong column is not a vulnerability. Open a "Wrong column" issue instead.

## What to expect

This is a small project kept by one person. A first reply usually comes within a week. Only the latest commit on `main` is supported.
